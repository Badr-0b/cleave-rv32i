## Where we are ✅

- **RTL complete (stages A–K)** — full RV32I single-cycle core: `cleave_core.v` integrating
  pc / imem / regfile / alu / immgen / branch / control / dmem, wrapped by `tt_um_cleave.v`.
- **Functionally proven** — `test/unit/tb_cleave_proof.v` runs the committed proof program end-to-end
  (every instruction group: LUI/AUIPC, all R/I ALU incl. shifts & SLT, SB/SH/SW → LB/LH/LW/LBU/LHU,
  all six branch conditions with poison/negative-controls, JAL/JALR call+return), parks at `BEQ x0,x0,0`,
  and asserts all 32 registers + memory + PC against an independent assembler/ISS golden.
  **`test/unit/run_unit_tests.ps1` → 10/10 passing.**
  - The ROM program is generated by `test/gen/asm.py` (load-bearing: regenerate → repaste ROM lines into
    `src/cleave_imem.v` and the golden array into `tb_cleave_proof.v`).
- **Waveforms captured** — build the proof bench with `-DDUMP` to emit `cleave_proof.vcd`; view with
  `cleave.gtkw` in GTKWave. (The brief red/X at t=0 is pre-reset and expected.)
- **Synthesis sanity done** — standalone yosys → sky130 (`synth/cleave.synth.v`, `synth/synth.ys`):
  **~9.4k std cells, 3,102 flops** (data RAM 64×32 + regfile 31×32 + PC/misc), no inferred latches,
  core area ≈ 136k µm². NOTE: **qflow re-synthesizes from RTL itself**, so this netlist is a cross-check
  reference, not qflow input.

## Immediate next action ▶ run qflow (sky130, in WSL2)

Follow **`docs/qflow-sky130-runbook.md`** (local file — see note below). In short:
1. **Setup (Part A):** create `…/ASIC/Projects/cleave/{source,synthesis,layout,log}`, copy the 10

## Remaining steps to the definition of done

| # | Step | Tool | Done when |
|---|------|------|-----------|
| 1 | Synthesis | qflow/yosys | gate netlist mapped to `sky130_fd_sc_hd` |
| 2 | Floorplan + place | graywolf | placement legal at ~30–40% utilization |
| 3 | Route | qrouter | 100% routed, no violations (expect a long run) |
| 4 | STA sign-off | OpenSTA | no negative slack at the chosen clock |
| 5 | **DRC clean** | Magic | `drc.log` → 0 errors |
| 6 | **LVS clean** | netgen | `lvs.log` → "Circuits match uniquely" ← **definition of done** |
| 7 | Render (optional) | KLayout / GDS3D | presentable GDS image for the writeup |
| 8 | Portfolio writeup | — | screenshots of render + the three sign-off logs |

**Caveats:** big design (3.1k flops → ~0.34 mm² die) means qrouter can take minutes to tens of minutes;
start with a **relaxed clock (30–50 ns)** so STA closes — this is a functional PoC, not an Fmax target.
It's no longer a TinyTapeout tile submission, so the large die is fine.
