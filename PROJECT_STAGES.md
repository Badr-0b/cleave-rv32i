# Cleave RV32I — Project Stage Checklist

At-a-glance tracker for the whole project. The detailed spec lives in the active plan
`~/.claude/plans/read-c-users-nitro-documents-github-clea-wobbly-comet.md`; the scope/endpoint is
defined in `.claude/OBJECTIVE_UPDATE.md`. This file is the checklist; those are the source of truth.

**Endpoint:** design-only proof of concept — a **DRC-clean + LVS-clean GDSII** of the Cleave RV32I
single-cycle core (full RV32I base ISA, 32×32 regfile, on-chip ROM/RAM), hardened through the
**qflow** stack against `sky130_fd_sc_hd`, with an optional KLayout/GDS3D render. No fabrication.

**Progress: 12 / ~19 stages done — Phase 1 RTL COMPLETE (A–K) + Phase 2 functional verification COMPLETE. Next: Phase 3 backend (qflow → sky130).**

Legend: `[x]` done & verified · `[~]` in progress · `[ ]` not started.

## Phase 1 — RTL design (11 stages, A–K)

Each module is `` `default_nettype none ``, covered by a persisted self-checking iverilog bench in
`test/unit/`, and registered in `info.yaml` `source_files` + `test/Makefile` `PROJECT_SOURCES`
before moving on. Run the whole module suite with `powershell -File test\unit\run_unit_tests.ps1`
(currently **10/10 passing** — 9 module benches + the `cleave_proof` integration bench).

- [x] **A. Fetch** — `cleave_pc.v` + `cleave_imem.v` (PC steps by 4; ROM word-read)
- [x] **B. Register file** — `cleave_regfile.v` (32×32, x0=0, dual read + debug port)
- [x] **C. ALU** — `cleave_alu.v` (10 ops: ADD/SUB/SLL/SLT/SLTU/XOR/SRL/SRA/OR/AND)
- [x] **D. Immediate generator** — `cleave_immgen.v` (I/S/B/U/J reassembly)
- [x] **E. Branch comparator** — `cleave_branch.v` (BEQ/BNE/BLT/BGE/BLTU/BGEU)
- [x] **F. Control unit** — `cleave_control.v` (full-ISA decode → control vector)
- [x] **G. Data memory** — `cleave_dmem.v` (byte-addressable RAM; SB/SH/SW + LB/LH/LW/LBU/LHU)
- [x] **H. Core integration — ALU path** — `cleave_core.v`: fetch→decode→regfile→ALU→writeback
- [x] **I. Core integration — loads/stores** — wire `cleave_dmem` + sub-word load extend
- [x] **J. Core integration — branches + jumps** — next-PC mux (branch/JAL/JALR, shared ALU adder), link write
- [x] **K. Observability + wrapper refine** — regfile debug byte → `uo_out` (`ui_in[4:0]`=reg, `[6:5]`=byte)

## Phase 2 — Functional verification (1 stage)

- [x] **Full proof program** — DONE (`test/unit/tb_cleave_proof.v`, generated by `test/gen/asm.py`,
      10/10). Exercises every instruction group (LUI/AUIPC, R/I ALU incl. shifts &
      SLT, SB/SH/SW→LB/LH/LW/LBU/LHU round-trip, each branch condition, JAL/JALR), ends in a
      `BEQ x0,x0,0` self-loop; **GTKWave** waveforms captured; reads result registers via the debug port and
      check against hand-computed values. *(Optional: riscv-tests / RISCOF conformance.)*

## Phase 3 — Backend to clean GDSII (qflow stack, 6 stages)

Harden `tt_um_cleave` (or `cleave_core` standalone) against `sky130_fd_sc_hd`. **Runbook + setup guide:
`ttsky-verilog-template/docs/qflow-sky130-runbook.md`** (local/gitignored). Note: a standalone yosys
sky130 sanity synth already exists (`ttsky-verilog-template/synth/`, ~9.4k cells / 3,102 flops, no
latches) — an area/DRC-risk reference; qflow re-synthesizes from RTL itself, so the stages below are
still pending.

- [ ] **Trial-harden** — early run to get the real area/tile number and surface SKY130-in-qflow
      friction before polishing
- [ ] **Synthesis** — Yosys → gate netlist (standalone sanity done; qflow's own run pending)
- [ ] **Floorplan + Place** — graywolf
- [ ] **Route** — qrouter
- [ ] **STA sign-off** — OpenSTA timing passes at the chosen clock
- [ ] **DRC + LVS clean** — Magic DRC clean **and** netgen LVS clean vs the synthesized netlist *(definition of done)*

## Phase 4 — Render (optional, 1 stage)
